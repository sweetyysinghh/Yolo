# Advanced Object Detection for Workplace Safety

## Overview

This project focuses on enhancing safety in workplace environments by using advanced object detection technology. By integrating YOLO and SSD algorithms, the system accurately identifies potential accident scenarios in real-time, ensuring that workers are protected from hazardous situations.

## Key Contributions

- **Accident Prevention:** Detects potential hazards in the workplace, reducing the risk of accidents.
- **Real-World Testing:** Conducted thorough testing to optimize the system for real-time detection in various work environments.
- **Safety Enhancement:** Improves the overall safety of the workplace by proactively identifying dangerous situations.
- **Accuracy:** Achieved an accuracy rate of 54.2% in detecting potential accident scenarios.

## Technologies Used

- **Python**
- **Machine Learning**
- **Flask**
- **YOLO V7**

## Installation & Usage

1. **Clone the Repository:**
   ```
   git clone https://github.com/sweetyysinghh/Yolo
   cd yolo
   ```

2. **Install Dependencies:**
   ```
   pip install -r requirements.txt
   ```

3. **Run the Application:**
   ```
   flask run
   ```
